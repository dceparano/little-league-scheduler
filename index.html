Priority Rules

The system recommends the correct order; an authorized administrator makes the final approval.
For a requested field/time:

1. Little League obligations always have priority over travel-team requests.
2. For Little League requests, the field's assigned division has first priority.
3. Remaining Little League requests are ranked by coaching seniority, then coach last name A–Z.
4. Travel teams are ranked by age, oldest first: 13U → 12U → 11U → 10U → 9U → 8U → 7U, etc.
5. Travel teams of the same age are ranked by coaching seniority, then coach last name A–Z.
